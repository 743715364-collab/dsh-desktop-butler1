# 桌面管家桌宠

把桌面管家 Electron 桌宠接入 DSH：随 DSH 启停，在设置页里管理，并自动使用 DSH 当前的默认模型与登录凭据。

## 功能

- **自动接入 DSH 模型**：优先使用 `ctx.llm` 与 DSH 默认模型，不需要在桌宠里另填 API Key。DSH 没有可用模型时，才回退到桌宠自己的 OpenAI 兼容配置。
- **语音对话**：DSH 内置 SenseVoice 识别 + Edge 神经语音（不可用时回落系统语音）。
- **语音命令**：打开软件、关闭软件、播放音乐、调节音量。
- **已安装软件清单**：读取开始菜单与 UWP 应用；首次扫描后缓存 7 天，可手动重建。
- **DSH 状态联动**：思考、干活、等确认、完成、出错时做对应动作。
- **设置页**：启动/停止/重启、模型、语音、闲聊模式、运行状态。
- **独立运行**：`pet/` 仍是完整 Electron 应用，也支持单独启动。

## 安装要求

- Windows 10 / 11
- DSH 0.2.1 或更新版本
- 使用 DSH 自带的 Electron，不需要单独安装 Electron

安装后首次启动会把内置的 `pet/` 复制到：

```text
%USERPROFILE%\.dsh\desktop-butler-app
```

配置和运行数据都写在这个用户目录，不写进插件包。

## 使用

安装后打开：

```text
设置 → 桌面管家桌宠
```

可以启动/停止桌宠、查看模型状态、选择语音和闲聊模式。

语音说：

```text
打开微信
播放音乐
调高音量
```

如果 DSH 默认模型可用，命令会通过 DSH 模型完成工具调用；如果 DSH 模型不可用，会回退到本地配置。

## 数据和权限

- 读取本机开始菜单应用列表，用于按名称打开软件。
- 使用麦克风时只在本机做语音识别；需要联网的 Edge 语音会连接微软语音服务。
- 模型请求走用户自己的 DSH 配置或用户自己填写的 OpenAI 兼容接口。
- 插件不读取、不复制 DSH 的原始 API Key。
- 对话历史只保存在桌宠进程内存中，重启即清空。

## 限制

- 命令模式依赖 Windows PowerShell 和开始菜单；便携版软件如果没有开始菜单快捷方式，可能无法按名称找到。
- DSH 默认模型不支持工具调用时，会回退到本地 Key 模式。
- 语音识别错误可能导致打开错误的软件；重要操作请确认。
